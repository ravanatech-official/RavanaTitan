# RavanaTitan

Ravana Tech Foundation Model and AI Intelligence Platform

RavanaTitan is a 314-billion parameter sparse Mixture-of-Experts (MoE) transformer architecture (incorporating Grok-1 weights and open-weight JAX/Haiku foundation designs) with a crystal-clear, aerospace-grade user experience.

## Key Architecture Specifications

- **Total Parameters:** 314B
- **Active Parameters per Token:** 86B (Top-2 of 8 Experts selected per token)
- **Transformer Layers:** 64
- **Attention Heads:** 48 Query Heads, 8 Multi-Query Key/Value Heads
- **Embedding Dimension:** 6,144 (intermediate FFN dimension: 49,152 with widening factor 8)
- **Positional Encoding:** Rotary Position Embeddings (RoPE)
- **Quantization:** 8-bit Quantized Weights (`QuantizedWeight8bit`)
- **Context Length:** 8,192 tokens
- **Vocabulary:** SentencePiece BPE with 131,072 tokens
- **Mesh Topology:** `local_mesh_config=(1, 8)` across 8x H100 GPUs

## Features of the Platform

- **Grok-Style Obsidian Chat:** Crystal clear, distraction-free conversational canvas, slash commands (`/moe`, `/specs`, `/hardware`, `/tokenizer`, `/code`, `/imagine`, `/raptor3`), and deep reasoning thought accordions.
- **Interactive Inference Playground:** Real-time token streaming, Top-2 expert gate assignments, sampling temperature/top-p controls, and detailed token logprob inspector.
- **8-Expert MoE Visualizer:** Live router probe, 64-layer depth routing heatmap, expert load-balancing telemetry, and expert registry.
- **Architecture & Tensor Graph:** Interactive layer calculation pipelines and JAX Haiku configuration source.
- **SentencePiece Studio:** Real-time subword token boundary colorization, compression ratio metrics, and vocabulary lookup.
- **Distributed Mesh & VRAM Calculator:** Hardware planning for 8x H100, 8x A100, and TPU v5p clusters across BF16, INT8, and INT4 precisions.
- **Developer Integration Hub:** Native JAX execution script, OpenAI-compatible REST API endpoints, and torrent checkpoint download guidance.

## Automated CI/CD (GitHub Push to Firebase Hosting)

Every push to `main` or `master` automatically triggers the GitHub Actions workflow (`.github/workflows/firebase-deploy.yml`) to build and deploy to Firebase Hosting.

### Required GitHub Repository Secrets

Go to your GitHub repository -> **Settings** -> **Secrets and variables** -> **Actions** and add:

1. `FIREBASE_SERVICE_ACCOUNT`: Your Firebase Service Account JSON key (Recommended).
   - Alternatively: `FIREBASE_TOKEN` (Generated by running `firebase login:ci`).
2. `FIREBASE_PROJECT_ID`: Your Firebase Project ID (e.g. `ravanatitan` or your chosen project ID).

## Running Locally

```bash
npm install
npm run dev
```

App boots on `http://0.0.0.0:3000`.
